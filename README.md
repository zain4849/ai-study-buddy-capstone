# AI Study Buddy

An AI-powered study assistant built as my capstone project.

## Project Goal

The goal of this project is to create a study companion that helps users learn more effectively with AI.

## Tech Stack

* Node.js
* JavaScript
* Git & GitHub

## Getting Started

```bash
git clone https://github.com/<your-username>/ai-study-buddy-capstone.git
cd ai-study-buddy-capstone
npm install
npm start
```
